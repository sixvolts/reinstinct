## Reinstinct 
Reinstinct is an inference platform designed to help make use of older Radeon Instinct MI50/MI60 cards and squeeze as much performance out of them as possible. 

32GB MI50 cards are especially interesting since they can be had for ~$500 on eBay as mid-2026. For 32GB of HBM2 that has 1TB/s of memory bandwidth, this is amazing hardware for the cost.

These cards have been somewhat abandoned by AMD and ROCm support was officially dropped after ROCm 5.7. The community has several workarounds to get them running on 6.3 and 7.x, but the performance isn't tuned well.
